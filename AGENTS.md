# AGENTS.md — инструкция для агентов

Проект: своя версия перевода романа К. Е. Антаровой «Две жизни» (RU → EN, затем PL) и сайт для чтения
с PDF/EPUB. Документация — в `docs/`.

## Перед любой работой

1. Прочитай `docs/PLAN.md` — где мы сейчас и что решено.
2. По задаче:
   - перевод, ревью, правка текста → **обязательно** `docs/TRANSLATION-PROCESS.md` целиком и его чек-лист §4;
   - сайт, сборка PDF/EPUB, скрипты → `docs/ARCHITECTURE.md`;
   - вопросы «что у нас есть» → `docs/INVENTORY.md`.

## Жёсткие правила

- `sources/` — только чтение. Оригинал правится в `content/ru/`, с объяснением в коммите.
- ID абзацев `{#pX-cYY-NNN}` не менять и не перенумеровывать. Перевод сохраняет тот же набор и порядок ID.
- Термины и имена — только по `translation/glossary.yml` и `translation/characters.yml`.
  Новое → `status: proposed`. Утверждённое (`approved`) меняет только владелец.
- Спорное место → вопрос в `translation/queries/<lang>/<chapter>.md`. Не выдумывать молча и не ставить заглушки.
- Перед коммитом текста — `npm run check` (когда появится).
- `legacy/` не трогать. `sources/en-legacy/` (старый перевод) — только справочно, текст оттуда не копировать.
- Ключи API и секреты не коммитить.
- Коммиты: `en: p1-c05 draft`, `glossary: …`, `site: …`, `tools: …`, `docs: …`.
