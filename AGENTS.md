# AGENTS.md — инструкция для агентов

Проект: своя версия английского (на основе старого перевода) и польского перевода романа
К. Е. Антаровой «Две жизни» и сайт для чтения с PDF/EPUB. Документация — в `docs/`,
принятые решения — в `translation/decisions.md`.

## Перед любой работой

1. Прочитай `docs/PLAN.md` — на каком этапе проект и что дальше.
2. Прочитай `translation/decisions.md` — принятые решения обязательны.
3. По задаче:
   - редактура, перевод, ревью, глоссарий → **обязательно** `docs/TRANSLATION-PROCESS.md` целиком и его чек-лист §5;
   - извлечение, выравнивание, сайт, сборки, скрипты → `docs/ARCHITECTURE.md`;
   - вопросы «что у нас есть» → `docs/INVENTORY.md`.

## Жёсткие правила

- Новый этап начинается **только по команде владельца** (DEC-008).
- `sources/` — только чтение. Оригинал правится в `content/ru/`, с объяснением в коммите.
- Старый английский перевод — **основа** для EN (DEC-003). Извлечение, выравнивание и редактура —
  **разные шаги** (DEC-014): на первых двух текст не меняется. Редактируем, не переписываем ради переписывания.
- ID абзацев принадлежат оригиналу и не перенумеровываются. Каждый ID покрыт в переводе ровно один раз
  и по порядку; `012a` — новый абзац оригинала, `012.2` — часть абзаца в переводе, `012..014` — склейка
  (ARCHITECTURE §3).
- Термины и имена — только по `translation/glossary.yml` и `translation/characters.yml`. Новое →
  `proposed` с контекстом. `core` утверждает только владелец; `secondary` — только при явном `agree`
  внешнего ревьюера; молчание — не согласие. Разные значения — разные записи; EN и PL утверждаются
  отдельно (DEC-015).
- Спорное место → вопрос в `translation/queries/<lang>/<chapter>.md`. Не выдумывать молча и не ставить заглушки.
- Ревью в два уровня (DEC-013): внутреннее (агенты со свежим контекстом) → commit + **push** → пакет
  `request.md`, привязанный к коммиту → стартовый промпт владельцу → **стоп**. Внешние модели запускает
  только владелец.
- Статус главы — **только** в `translation/status.yml` (DEC-016).
- Перед коммитом текста — `npm run check` (когда появится).
- `legacy/` не трогать. Ключи API и секреты не коммитить.
- Коммиты **без трейлеров соавторства** (`Co-Authored-By`, `Claude-Session` и т. п.) — DEC-006.
  Формат: `ru: …`, `en: p1-c01 revision`, `glossary: …`, `review: …`, `tools: …`, `site: …`, `docs: …`.
