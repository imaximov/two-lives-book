# Калибровочный набор

Отрывки для **слепого сравнения моделей-редакторов** (PLAN, этап 5; DEC-012) и для проверки любой будущей
смены модели. Четыре прозаических отрывка разных жанров плюс стихотворение, которое оценивается отдельно.

Каждый файл — RU-оригинал и старый английский перевод, разложенный по блокам с каноническими ID
(как в главах, ARCHITECTURE §3). Контекст до и после показывается для понимания и не оценивается.
Выравнивание всех связей в окне и контексте проверено вручную (`review: done` в
`translation/legacy-en/alignment/<глава>.yml`); остальная часть этих глав выровнена только автоматически
и не проверялась.

Состав — `passages.yml`. Пересборка: `python -m tools.calibration.build`.
Промпт и критерии сравнения появятся на этапе 5, после стайлгайда и ядра глоссария.
